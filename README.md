# 🦷 Clínica Odontológica

Este projeto consiste em um site institucional moderno e responsivo para uma clínica odontológica, desenvolvido com foco em proporcionar uma
excelente experiência ao usuário e apresentar os principais serviços da clínica de forma clara e profissional.

O objetivo do projeto é oferecer uma navegação intuitiva, destacando informações importantes como especialidades, equipe, diferenciais, depoimentos
de pacientes e formas de contato, facilitando o agendamento de consultas.

## 🚀 Funcionalidades

* Página inicial moderna e responsiva;
* Seção sobre a clínica;
* Apresentação dos serviços odontológicos;
* Área com informações da equipe;
* Depoimentos de pacientes;
* Formulário de contato;
* Botão de atendimento via WhatsApp;
* Layout adaptado para dispositivos móveis, tablets e desktops.

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Responsividade com Flexbox e CSS Grid

## 🎯 Objetivo do Projeto

Este projeto foi desenvolvido para aprimorar habilidades em desenvolvimento Front-End, aplicando boas práticas de HTML semântico, estilização
com CSS e interatividade com JavaScript, criando uma interface moderna, organizada e de fácil utilização.

## 📱 Responsividade

O site foi projetado para oferecer uma experiência consistente em diferentes tamanhos de tela, garantindo acessibilidade e usabilidade em qualquer dispositivo.
